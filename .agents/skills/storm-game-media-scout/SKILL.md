# STORM Game Media & Metadata Scout

## Назначение
Автоматическое наполнение игровых коллекций и лаунчеров (`STORM GOG LAUNCHER`, `STORM SWITCH BOX`, `STORM GAMES INFO`, `STORM RETRO`):
1. **Сбор медиа-данных**:
   - Автоматическая загрузка официальных обложек (covers), баннеров (hero/grid), логотипов на прозрачном фоне (clearlogo) и снимков экрана из Screenscraper, SteamGridDB, TheGamesDB, IGDB.
2. **Генерация 3D-боксов**:
   - Создание объёмных трёхмерных коробок игр (Nintendo Switch, PS4, Retro) с реалистичным корешком и акцентными тенями.
3. **Пакетная обработка**:
   - Сканирование директорий с ROM-файлами и играми, сопоставление по контрольным суммам и TitleID.

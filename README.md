# STORM SWITCH

## **О проекте**
**STORM SWITCH** - высокопроизводительный мультиплатформенный эмулятор гибридных игровых консолей **Nintendo Switch** и **Nintendo Switch 2** для платформ **Windows PC** и **Android**. Проект ориентирован на максимальную производительность, оптимизацию компиляторов JIT и NCE, универсальную стабильность конвейера Vulkan на всех настольных и мобильных видеочипах, потоковую поддержку сжатых игровых контейнеров (`NSZ / NCZ / XCZ` на лету), нативную поддержку пакетов нового поколения (`.nup`), архитектуру Tegra T239 (Ampere), сетевые сервисы NPLN, облачную синхронизацию сохранений **STORM SAVE SYNC**, расширенную базу автопрофилей **GameFix Database** и фирменную визуальную систему **STORM AURORA FLUID**.

## **Происхождение и форки**
**STORM SWITCH** является высокопроизводительным форком эмулятора **Eden**, объединяющим и развивающим инженерные наработки проектов **Yuzu**, **Citron**, **Sudachi**, **Ryujinx**, **Lemon-Project**, **Skyline / Strato**, а также передовых исследовательских проектов архитектуры следующего поколения **Eglantine**, **Orchid**, **BananaNative**, **Lichii**, **playDB-CNT**, **Pound** и **Oboromi**.

## **Технологический стек**
- **Языки программирования**: C++20, C, Kotlin, Java, CMake
- **Графический стек**: Vulkan (Desktop & Mobile), Qualcomm Adreno Turnip / Freedreno Extensions, ARM Mali / PanVK Optimizations, SPIRV-Cross, Sirit, Shader Recompiler, AMD FidelityFX (FSR / CAS), DLSS Active Rectangles, скалярная декомпозиция невыровненных SSBO в SPIR-V, транслятор микрокода Ampere
- **Архитектура Switch 2**: Tegra T239 HLE/LLE, многоочередная изоляция `nvhost_tsg_gpu` VEID, синхронизация снапшотов GPFIFO, сервис системных шрифтов Switch 2 Font Service (`pl:u`)
- **Компиляция кода и ЦП**: Dynarmic (ARM64/ARM32 JIT Recompiler), Native Code Execution (NCE) для Android ARM64, поддержка инструкций ARMv8-A / ARMv8.5-A PAC и BTI, аппаратная диспетчеризация P-ядер гибридных процессоров Windows
- **Память и виртуализация**: Разреженное адресное пространство VMM (4 / 6 / 8 / 12 GiB) с ленивым выделением страниц и неблокирующим отслеживанием страниц GPU (`Nx2MayBeGpuWritten`)
- **Аудио**: Cubeb, SDL Audio, OpenSL ES / Oboe
- **Декомпрессия и форматы**: Контейнеры `.nup` (Nintendo Switch 2 Package), Zstandard (блочное и solid потоковое декодирование `NSZ / NCZ / XCZ` с кольцевым LRU-кэшем), `hactool`, LZ4
- **Мультимедиа и видео**: Аппаратное и программное декодирование видеопотоков H.264 / VP9 / AV1 (FFmpeg)
- **Сеть и экосистема**: Локальный мультиплеер, протокол NPLN (`playDB-CNT`), каталог **STORM GAMES WORLD**, облако **STORM SAVE SYNC**, интеграция **GameBanana Mods**, **TitleDB** и **AmiiboAPI**
- **Пользовательский интерфейс**: Qt (Windows), Material / Native Android UI (Android), дизайн-система **STORM AURORA FLUID**

## **Ключевые возможности**
- **Прямая потоковая работа со сжатыми архивами (`NSZ / NCZ / XCZ`)**: Мгновенный запуск сжатых дампов и объединённых контейнеров (`Base + Update + DLC`) на лету без предварительной распаковки на диск с кольцевым LRU-кэшем Zstandard.
- **Расширенная база автопрофилей (`GameFix Database`)**: Более 450 проверенных профилей автоматической настройки памяти, точности компилятора CPU, синхронных/асинхронных шейдеров, барьеров обратной связи Vulkan и текстур ASTC под конкретные коммерческие игры и порты (*Super Mario Bros. Wonder*, *The Legend of Zelda: Tears of the Kingdom*, *Breath of the Wild*, *Diablo II: Resurrected*, *Castlevania: Belmont's Curse*, *Red Dead Redemption*, *Metroid Dread* и др.).
- **Универсальная оптимизация Vulkan и предпрогрев шейдеров**: Многопоточная компиляция дискового кэша конвейеров Vulkan, барьеры compute-шейдеров и специализированные профили под Qualcomm Adreno (Turnip / Proprietary), ARM Mali (Bifrost / Valhall / Immortals), Samsung Xclipse, Imagination PowerVR, NVIDIA GeForce, AMD Radeon и Intel Arc / Iris Xe.
- **Быстрые сохранения `Zstd` и внутриигровой сайдбар**: Мгновенные Quick Save / Quick Load с разреженным кодированием страниц памяти и быстрый вызов панели настроек и телеметрии прямо во время игры (`F10` на ПК и боковая панель на Android).
- **Единый центр каталогов и модификаций**: Встроенные модули **STORM GAMES WORLD**, **STORM SAVE SYNC** (трёхстороннее разрешение конфликтов сохранений между ПК и Android), **Менеджер читов**, **Менеджер Amiibo** и **Моды GameBanana / LayeredFS**.
- **Поддержка архитектуры Nintendo Switch 2 (Tegra T239 / Ampere)**: Изоляция очередей VEID, понижение инструкций шейдеров Ampere (`IMAD.HI`, `OUT`, `LEPC`, `MUFU`), выравнивание вершинных буферов `69B -> 72B`, контейнеры `.nup`, наследование DLC Switch 1, области апскейла DLSS, Sparse Tile Mapping и редирект NPLN.

## **Поддерживаемые платформы и форматы**
- **Операционные системы**: Windows 10 x64, Windows 11 x64, Android (ARM64-v8a: Snapdragon / MediaTek Dimensity / Exynos / Tensor)
- **Поддерживаемые консоли**: Nintendo Switch, Nintendo Switch 2 (Horizon OS / NX2)
- **Игровые форматы**: `NUP`, `NSP`, `NSZ`, `XCI`, `XCZ`, `NRO`, `NSO`
- **Совместимая экосистема**: STORM SWITCH, Eden, Citron, Sudachi, Yuzu, Suyu, Torzu, Lemon-Project, Ryujinx

## **Установка и запуск**
1. Перейдите в раздел **Releases** репозитория GitHub или на страницу проекта в каталоге **STORM GAMES WORLD**.
2. **Для Windows**:
   - **Мастер установки**: скачайте подписанный автономный установщик `STORM_SWITCH_Setup.exe` и выберите стандартный или портативный режим установки.
   - **Портативная сборка**: скачайте архив `STORM_SWITCH_Windows11.zip` (для Windows 11 x64) или `STORM_SWITCH_Windows10.zip` (для Windows 10 x64), распакуйте в любую папку и запустите `STORM_SWITCH.exe` (системные библиотеки MSVC CRT уже встроены).
3. **Для Android**: скачайте подходящий подписанный пакет APK (поддерживается бесшовное обновление поверх предыдущих сборок по схеме APK Signature Scheme v3 Key Rotation):
   - `STORM_SWITCH.apk` - основная сборка для современных устройств ARM64 с поддержкой кастомных драйверов Qualcomm / Turnip;
   - `STORM_SWITCH_LEGACY.apk` - сборка расширенной совместимости для видеочипов ARM Mali, PowerVR, Xclipse и более ранних Adreno;
   - `STORM_SWITCH_SDK27.apk` - сборка максимальной совместимости для устройств предыдущих поколений Android.
4. Укажите папку с играми, установите системные ключи (`prod.keys`) и прошивку (Firmware) через меню настроек эмулятора.
